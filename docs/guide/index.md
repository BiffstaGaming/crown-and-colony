# Crown &amp; Colony — Governor's Handbook

Welcome, Governor. This is the complete player's guide to **Crown &amp; Colony**: what you are
trying to achieve, how to start a game, the systems you will spend your time in, the keys you
press, and how a game ends. It assumes **no prior knowledge** of the original *Colonization* —
if you have played it, everything here will feel familiar; if you have not, start at the
beginning and you will be running a thriving New-World empire in no time.

!!! tip "New here? Start with the first chapter."
    [**Welcome &amp; Getting Started →**](01-welcome.md) covers what the game is and walks you
    through founding your first colony in about ten minutes.

## Help inside the game

This written guide is the deep reference, but the game keeps help close at hand too:

| Where | How to open it | What it gives you |
|---|---|---|
| On-screen key legend | Press `F1` in-game | A pop-up list of every active shortcut |
| In-game **Help** | *Help* on the title screen or pause menu | The goal, the core loops and a controls reference |
| **Colopedia** | Press `C` | The in-game reference of units, goods and buildings |
| **Tutorial card** | On by default in a new game | Step-by-step prompts through the opening loop |
