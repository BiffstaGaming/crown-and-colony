## Implementation warnings

- Armed units and Mounted Police should increase tension when near First Nations communities.
- Pastoral improvements should create Country Pressure if built without agreement.
- Telegraph/rail routes should require corridor agreements or create significant tension.
- Gold should be profitable but socially destabilising.
