# Australian Federation Mode — Documentation Pack

This pack is a ClickUp-ready Markdown documentation set for an Australian mode inspired by **Sid Meier's Colonization / FreeCol**.

The proposed historical campaign runs from **1788 British settlement to 1901 Federation**. It replaces the American independence-war storyline with a **Federation victory arc**: the player builds settlements, economy, infrastructure, diplomacy, civic institutions, and support for Federation across the six Australian colonies.

## Design position

- **Historical campaign:** British Australia, 1788–1901.
- **Primary victory:** Federation / Commonwealth proclamation, not a war of independence.
- **Founder equivalent:** `Historical Figures`.
- **Liberty equivalent:** `Civic Voice` / `Federation Support`.
- **Congress equivalent:** `Federation Convention`.
- **Native settlement equivalent:** First Nations `Country`, `Communities`, `Respect`, `Tension`, and `Knowledge Exchange` systems.
- **Event structure:** Events are mostly **conditional**, not forced. Some are scenario setup events, but most require prerequisites such as date, figure unlocked, colony state, resource discovery, regional contact, diplomacy state, or civic progress.
