# Fonts — provenance

**Cardo** (`Cardo-Regular.ttf`) — the project's UI font, used by `ColonyTheme`
for all menu/screen text. A classical, period-appropriate serif suited to the
1600s setting and legible at UI sizes.

- **Source:** Google Fonts mirror — https://github.com/google/fonts/tree/main/ofl/cardo
  (`ofl/cardo/Cardo-Regular.ttf`), by David J. Perry / Scholars Fonts.
- **License:** SIL Open Font License 1.1 (`Cardo-OFL.txt`, kept alongside the
  font). Copyright (c) 2002-2011, David J. Perry (hospes02@scholarsfonts.net).
  OFL is compatible with GPL-v2 distribution: the font is a data asset under the
  OFL; the game code stays GPL v2. Attribution + the OFL text are retained here.
- Recorded in the Asset Register (ClickUp doc 05).

Replaces the engine default font (ADR-013: assets may be swapped later — keep
this file and the Asset Register current if so). A separate display/title face
may be added later; for now Cardo is used at every size.
